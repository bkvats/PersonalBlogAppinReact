# Personal Blog Application 📝

A personal blog application where users can read, write, and manage blog posts. This project showcases a fully functional blogging platform with a user-friendly interface and a third party api integration.

## 🚀 Features

- **Create & Manage Posts**: Users can write, edit, and delete their blog posts.
- **Rich Text Editor**: Write engaging content with a feature-rich editor.
- **Responsive Design**: Fully optimized for all screen sizes.
- **User Authentication**: Secure user registration and login.
- **SEO-Friendly**: Optimized for search engines with metadata and clean URLs.

## 🛠️ Technologies Used

- **Frontend**: React.js, React-Router-DOM, React-Redux, Tailwind CSS.
- **Backend**: Appwrite's API Support with power bucket.
- **Hosting**: Vercel.

## 🖥️ How It Works

1. **Homepage**:
   - Displays a list of published blog posts with titles, excerpts, and author details.

2. **Write Post**:
   - A dedicated page for creating or editing blog posts with a rich text editor.

3. **Post Details**:
   - Individual blog posts with full content and related posts.

4. **User Authentication**:
   - Users must log in to create or manage blog posts.
